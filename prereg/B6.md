# B6: reliance or compliance, and where the harm of a wrong graph lives

Nguyễn Dương Hiếu, 25 September 2026.

This file was committed and pushed **before the first B6 call was sent**. The commit that adds it is the registration, and its timestamp is on GitHub. It is not edited after that commit; deviations are reported with the results, not written into this file.

## 1. Why

Two findings of the project rest on data that suggested them.

1. **Where the harm of a wrong graph lives.** On the `ate` and `ett` items of three samples already answered (price400, n600 and the confirmatory sample), the harm of a reversed edge sits almost entirely in reversals that leave the graph with no directed path from X to Y on an item whose answer is Yes: the model then answers No. A reversal that changes the estimand but not the implied answer costs nothing measurable, and neither does one that keeps the path and changes only the adjustment set (REPORT section 4.8, `scripts/analyze_answer_change.py`). This was found after the data were seen.
2. **Reliance or compliance.** Every graph block of every earlier phase ended with "Use this causal structure when reasoning." A model that follows a wrong graph may be relying on it, or obeying the instruction. The earlier phases cannot tell the two apart.

B6 tests the first on questions never asked before, and separates the second by sending the same graphs without the instruction.

## 4. The unit and the groups

A **draw** is one item at one dose k. Its **harm** is `DR_kk - ORACLE` (correct = 1, else 0), averaged over the three models and the two lexicons, parsed answers only (an unparsed answer drops out of its pair). `h_NI` is the same with `DR_kk_NI - ORACLE_NI`.

Each draw is placed in a group by `scripts/analyze_answer_change.py` at this commit. The item is matched to its SCM in `data/cladder/cladder-meta.json` through the probabilities stated in its `reasoning` field. The answer the shown graph implies is what a reasoner who believed that graph would conclude from the SCM's true distribution: no directed X -> Y path gives effect 0 and answer No; otherwise backdoor adjustment on observed variables, then front-door, then an instrument.

| Group | Definition |
|---|---|
| estimand kept | `classify_perturbations.same_estimand` holds |
| estimand changed, answer kept | the estimand changes; the implied answer equals the item's label |
| answer changed, path cut | the implied answer differs from the label, and the shown graph has no directed X -> Y path |
| answer changed, path kept | the implied answer differs from the label, and a path remains (backdoor, front-door or instrument) |

## 5. The five tests

| Test | Quantity | Prediction |
|---|---|---|
| M1 | mean harm over "answer changed, path cut" draws | negative |
| M2 | mean harm over "estimand changed, answer kept" draws | equivalent to zero within 5 points |
| M3 | mean harm over "path cut" draws minus mean harm over "answer changed, path kept" draws | negative |
| R1 | mean `h_NI` over "path cut" draws | negative: without the instruction, a path-cutting graph still hurts |
| R2 | mean of `h - h_NI` over "path cut" draws | equivalent to zero within 5 points: the instruction changes the harm by less than 5 points |

M1 to M3 test the mechanism, R1 and R2 reliance against compliance. If R1 is confirmed and R2 is not, the direction of `h - h_NI` says how much of the harm the instruction carries; that reading is exploratory.

## 6. Decision rule

- Bootstrap over items, 4,000 draws, every draw of an item resampled with it. Two-sided p is `stats.boot_p` (floor 2/4000). M2 and R2 are two one-sided tests against -5 and +5; p is the larger one-sided bootstrap p (floor 1/4000), which amounts to the 90% interval lying inside (-5, +5). M3 resamples items once and takes both means from the same resample.
- Holm across the five, family-wise alpha 0.05.
- **Confirmed**: adjusted p < 0.05 and the estimate in the predicted direction (M2, R2: adjusted TOST p < 0.05). **Contradicted**: adjusted p < 0.05 in the opposite direction. Otherwise **not confirmed**.
- Seed rule: repeated at bootstrap seeds 20260907 (primary), 1, 2, 3, 4. A verdict that is not the same at all five is reported as borderline.
- Every estimate is reported with its 95% interval whatever its verdict.

## 7. The analysis code is the exploratory construction

`scripts/analyze_b6.py` computes the five tests. Before it reads a B6 record it runs the same functions on the exploratory draws and stops unless M1 and M2 equal the rows `analyze_answer_change.py` publishes (`results/cladder/answer_change_harm.csv`, lexicon `both`). At this commit:

| Test | Exploratory draws, recomputed | Published row |
|---|---|---|
| M1 | -29.61 [-33.62 ; -25.80], 461 draws on 260 items | `answer_change_harm.csv`: both, answer changed, no path: -29.61 [-33.62 ; -25.80] |
| M2 | +1.19 [-0.31 ; +2.74]; 90% interval [-0.07 ; +2.48] | `answer_change_harm.csv`: both, estimand changed, answer kept: +1.19 [-0.31 ; +2.74] |
| M3 | -30.79 [-36.02 ; -25.60] | none (computed here) |

Run through the decision rule above as a code test, the exploratory data would give M1, M2 and M3 confirmed.

The exploratory data carry no instruction-free condition, so R1 and R2 have no exploratory value. These numbers are not evidence for M1 to M3; they were found on those data.

## 8. Registered but not tested

Reported with the results, with no verdict:

- The sensitivity analysis: unparsed answers scored as wrong instead of dropped.
- Per group and per dose: harm with and without the instruction; `ORACLE_NI - ORACLE`, `ORACLE - RAW`, `ORACLE_NI - RAW`, `DR_k1 - RAW`, `DR_k1_NI - RAW` per lexicon.
- **The direction probe** (`scripts/probe_direction.py`). For every edge u -> v of the 484 confirmatory items that were sent, the names on u and v under `KEEP` and under `PERMUTE` (the names of H3a), in an order flipped at random per pair, and one question to the same three models at temperature 0: in the real world, does a change in the first cause a change in the second, the other way round, or neither? Reported: the share that agrees with the item's edge, runs against it, or is "neither", per lexicon and model. It asks whether the permuted names of H3a carry a wrong direction at all. At most 1.19 USD, capped at 1.30.

## 9. What will not be done

- No test is added to or removed from the five after this commit; any other analysis of these records is exploratory.
- No data are replaced. A stopped run resumes from the cache.
- If a cap stops a run, a test is computed only if all its data exist; the others are reported as not run.

## 10. Limits known in advance

- CLadder only, one prompt frame, the GPT-4.1 family.
- The groups hold for `ate` and `ett`. The implied answer is defined on the SCM's true distribution; the prompt states only the numbers the true estimand needs, so for "answer changed, path kept" a model could not compute the wrong formula from what it is shown. M3 compares two kinds of wrong graph, not a model that computes and one that does not.
- Removing the instruction leaves "The causal structure of this world is:", which still asserts the graph. B6 separates the graph from the instruction to use it, not the graph from a claim that it is true.
- At temperature 0 about 15% of answers change when asked again; this is noise inside every estimate.
