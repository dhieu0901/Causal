# B7: the six confirmatory tests on a current reasoning model

Nguyễn Dương Hiếu, 25 September 2026.

This file was committed and pushed **before the first B7 call was sent**. The commit that adds it is the registration, and its timestamp is on GitHub. It is not edited after that commit; deviations are reported with the results, not written into this file.

## 1. Why

The confirmatory phase (`prereg/CONFIRMATORY.md`) tested six hypotheses on the GPT-4.1 family, a model family from April 2025. A reader will ask whether they hold for a current model that reasons before it answers. B7 asks exactly the same questions of one such model, with nothing else changed.

## 2. Sample, conditions, tests: those of the confirmatory phase

- The same draw: `pilot.make_items(n=1000, seed=20260925, kmax=1, drop_nonsense=True, exclude_ids=prereg/excluded_ids.txt)`, the same 484 causal items (`--causal-only`), the same prompts from `src/prompts.py` and `src/lexical.py`, the same conditions: `KEEP` and `PSEUDO` under `RAW`, `ORACLE`, `DR_k1`, `DR_k2`, `DR_k3`; `PERMUTE`, `IRRELEVANT`, `SYMBOL` under `RAW`.
- The same six tests, H1, H2, H3a, H3b, H4-KEEP and H4-PSEUDO, as defined in section 4 of `prereg/CONFIRMATORY.md`, with the same predictions.
- The same decision rule (section 5 there): bootstrap over questions, 4,000 draws, Holm across the six, family-wise alpha 0.05, TOST within 5 points for H3a, bootstrap seeds 20260907, 1, 2, 3, 4, a verdict that changes with the seed reported as borderline.
- The same sensitivity analysis: unparsed answers scored as wrong.
- The same code: `scripts/analyze_confirmatory.py`, family `luna`, which reproduces the published n600 rows before it reads any record.

## 3. What differs: the model

- `gpt-5.6-luna` through the OpenAI API, a reasoning model. Reasoning effort not set (the model's default), temperature not set: the model refuses temperature 0 and accepts only its default of 1, so unlike the GPT-4.1 runs its answers carry sampling noise. At most 4,000 output tokens, hidden reasoning included; an answer cut off is scored unparsed.
- One model, not a family of three: each test averages over one model instead of three.

## 4. Cost

Estimated 5.76 USD: 6,036 calls at the mean of 12 uncached feasibility calls on confirmatory prompts (209 input and 760 output tokens; list price 0.20 and 1.20 USD per million). Those 12 calls were sent directly, not through the cache, and are not data. Hard caps 3.30 (`KEEP`), 3.30 (`PSEUDO`) and 0.80 for each of the three ladder runs, 9.00 USD in all; a cap covers every attempt of its run. Exact commands: `scripts/run_b7.sh`.

## 5. How the result is read

- Each test is decided on its own by the rule above. The GPT-4.1 verdicts do not change.
- A comparison between `gpt-5.6-luna` and GPT-4.1 on the same items is descriptive, not a test.

## 6. What will not be done

- No test is added or removed after this commit; anything else is exploratory.
- No data are replaced. A stopped run resumes from the cache.
- If a cap stops a run, a test is computed only if all its data exist.

## 7. Limits known in advance

- One model, at temperature 1.
- The confirmatory items were already asked of GPT-4.1; they are new to `gpt-5.6-luna`, but these results are no longer a first look at fresh items for the project as a whole: the hypotheses and the items are the same as in the confirmatory phase.
- The model's reasoning is hidden; only its answer is scored.
